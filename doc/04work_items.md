# 今後の作業リスト

更新日: 2026-09-22

以下の順序・優先度は提案であり、着手の決定ではない。OR検索・読書状態・MCP／SKILLの保留は継続する。設計上の決定事項はdoc/01、実施した検証結果はdoc/02に記録する。

## 現在できていること

- TypeScript・pnpm・Biomeとコミット前チェックを備えた開発環境。
- Kindleの購入済み一覧取得・保存JSON取り込み、BOOK☆WALKERの先頭25冊の部分取得・取り込み。
- 両ストアの所有情報と書誌情報を分けたSQLite保存、語句AND検索・出版社絞り込み・詳細取得。
- 所有・書誌のストア別アダプター化と、架空の第3ストアによる共通経路の検証。
- 実蔵書DBへの2ストアのデータ取り込みと横断検索。書誌補完は少数のみで、全所有書籍の分類検索を網羅する状態ではない。

## 現在の検討テーマ: 検索ユースケースとE2E評価

このフェーズでは実装や検索実行を行わない。まず、実際に尋ねそうな質問と期待する答えを決める。E2E検証はその後の独立した作業とする。

### ユースケース候補

| ID | ユーザーが行う質問の例 | 期待する結果 | 現時点で予想される依存事項 |
|---|---|---|---|
| U1 | 「Pythonをこれから学ぶのに良さそうな本は持っている？」 | 所有書籍だけから候補を返し、該当理由を説明できる | 書名・紹介文・分類等の補完状況。一致箇所の表示 |
| U2 | 「Blenderで3Dモデリングを学べる本を探して」 | Blenderと3Dモデリングの両方を考慮した候補を返す | AND・ORの使い分け、同義語、書誌不足 |
| U3 | 「手持ちの推理小説を見せて」 | 小説かつ推理・ミステリーに該当する候補を返す | 種類とジャンルの区別。単なる紹介文中の一致を分類と断定しない |
| U4 | 「漫画／技術書／ライトノベル／R18の本を探して」 | 指定した種類・年齢区分の候補を返す | ストア分類の違い、R18の明示的な根拠、未補完と非該当の区別 |
| U5 | 「この出版社の本を持っている？」 | 出版社欄が一致する所有書籍を返す | 書誌補完済み商品のみ判定可能。レーベルとの区別 |
| U6 | 「この本と同じ著者の本をほかにも持っている？」 | 起点となる所有書籍を特定し、同じ著者の別商品を返す | 起点の指定方法、著者表示の余分な文言、原作・作画等の扱い |
| U7 | 「このタイトルの本をもう買っている？」 | ストア横断で所有候補を返し、版・巻・ストアを確認できる | 部分一致の過剰一致。別版や同名商品を自動統合しない |
| U8 | 「このシリーズは何巻まで持っている？」 | 同一シリーズとして確認できる所有商品を列挙する | シリーズ情報の補完、ストア内シリーズURL、巻順の根拠 |
| U9 | 「続きを買っているけれど、まだ読んでいない本は？」 | 読了した巻より後にある、明示的に未読の所有巻を返す | 読書状態と読む順序。現在は保留中 |
| U10 | 「買ったまま一冊も読んでいないシリーズは？」 | 所有巻がすべて明示的に未読のシリーズを返す | 読書状態、不明の扱い、シリーズの範囲。現在は保留中 |
| U11 | 「最近買った本から次に読む候補を出して」 | 購入日の新しい所有書籍から候補を返す | 購入日表示の比較方法、候補の絞り込み・並び順 |
| U12 | 「検索結果がないのは、持っていないから？ 情報不足だから？」 | 未所有、書誌未取得、条件不一致を区別して説明する | 補完状況と一致理由の表示。検索だけでは未所有を断定しない |

U1〜U12は候補であり、すべてを初期目標にはしない。まず日常的に使う質問を選び、質問文、起点となる本や条件、期待する候補、許容できない結果を具体化する。個人の蔵書に基づく期待値はGitへ登録せず、ローカルの評価データとして扱う。

### E2E検証で確認する共通項目

- 質問を現在のCLI引数へ無理なく変換できるか。
- KindleとBOOK☆WALKERを横断した所有書籍だけが返るか。
- 期待する候補が含まれ、明らかな誤一致を説明または除外できるか。
- 書名、著者、出版社、紹介文、分類、シリーズ、レーベル、ジャンルのどこに一致したか分かるか。
- 書誌未取得のため検索対象にならない本と、本当に条件に合わない本を区別できるか。
- 件数上限とページ送りを使って結果全体を確認できるか。
- 0件を「未所有」と断定せず、検索語・機能・データのどれが不足したか判断できるか。
- 結果が期待と異なる場合、「検索機能不足」「書誌データ不足」「読書状態待ち」「ユースケース定義不足」のどれかに分類できるか。
